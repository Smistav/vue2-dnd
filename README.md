# vue2-dnd

Тестовое задание Kanban доски

### Стэк технологий

Vue, JS, HTML, Typescript

### Для развертывания проекта

1. Клонируйте репозиторий
2. Установите зависимости

```sh
npm install
```

3. Запустите проект

```sh
npm run serve
```

### Реализовано

- Пермещение карточек
- Добавление новых
- Сохранение данных Доски(колонок, карточек и данных) в localStorage
